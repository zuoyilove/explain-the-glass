A deterministic Node program that writes the one sentence a house cat would say in its own defence, five seconds after sweeping a glass off the table. No apology, no confession — the cat caught the glass hiding a rival cat (its own reflection) in the house uninvited, so it evicted them both: the glass and the phantom cat.

## Run it

```sh
node main.ts
```

This writes the sentence to `/output/entry.txt` (set `ENTRY_OUTPUT` to point it at a scratch path for a local run instead). Node 22.18 or later, no dependencies, no network, no randomness — every run writes the same 69 characters.
